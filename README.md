# Enterprise Stack: Zero to Architect

Hi, I'm **Himanshu Kumar/ Dwivedi** — Technical Lead & Solution Architect with **8 years** of experience building enterprise systems.

This is my catch-all repo for everything that sits *around* the application: message brokers, caches, databases, integration platforms and the infrastructure that runs them. The tools that never fit neatly into one course but decide whether a system holds up in production.

---

## What you'll get from here

**Messaging & streaming**
- Kafka — topics, partitions, consumer groups, offsets, exactly-once, schema registry
- RabbitMQ / SQS — queues vs topics, DLQ, ordering, retry strategy

**Caching & in-memory**
- Redis — data types, TTL, eviction policies, pub/sub, distributed locks, cache-aside vs write-through

**Databases**
- MongoDB — document modelling, indexes, aggregation pipeline, sharding, replica sets
- PostgreSQL — indexing, query plans, transactions, isolation levels
- Choosing between SQL, document, key-value and vector stores

**Integration platforms**
- MuleSoft — Anypoint, DataWeave, API-led connectivity, error handling, CloudHub
- API gateways, rate limiting, versioning, idempotency

**Infrastructure**
- Docker & Kubernetes basics, CI/CD pipelines, observability (logs, metrics, traces)
- AWS pieces I actually use: S3, Lambda, SQS, Secrets Manager

For each tool: what problem it solves, when **not** to use it, the config that bites people, and a small runnable example.

---

## How this repo is built

I add one folder per tool as I work through it. Each folder holds my notes plus a minimal working setup — usually a `docker-compose.yml` and a script you can actually run.
